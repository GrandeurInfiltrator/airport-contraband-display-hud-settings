## 🎯 What This Does

This project documents how to recognize and troubleshoot **display & hud settings** in **Airport Contraband**. It focuses on **Display scaling, fullscreen behavior and interface visibility** with targeted checks, patch awareness, and reproducible testing so players can narrow down the actual cause instead of guessing.

## ✨ Features

- Tests HUD visibility at native monitor resolution and alternate display modes.
- Checks whether Windows scaling or multi-monitor setups are affecting UI placement.
- Compares screen captures before and after each HUD or fullscreen adjustment.

## 🔎 Symptoms Covered

- HUD labels are clipped or appear at the wrong size.
- Fullscreen resolution differs from the monitor’s native resolution.
- UI elements become hard to read after changing display mode.

## 🛠️ Troubleshooting — Step by Step

1. **Update the game.** The launch-day update included HUD and graphics adjustments; retest on the latest build.
2. **Start at native resolution.** Select the monitor’s native resolution and test fullscreen or borderless mode.
3. **Check Windows display scaling.** Note your Windows scaling percentage and whether you use multiple monitors.
4. **Change only one setting.** Compare UI layout after each resolution or display-mode change.
5. **Capture a reproducible screenshot.** Include game version, monitor resolution and affected HUD panel in a bug report.
